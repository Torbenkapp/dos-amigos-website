# Dos Amigos Website

Official website for Dos Amigos - Organic Burrito Foodtruck

## 🌯 About

Dos Amigos is a food truck business built by two engineering students who combined their skills and passion for good food to create something special. We serve organic burritos made with love and high-quality ingredients.

## 🚀 Deployment

This website is automatically deployed to GitHub Pages using GitHub Actions.

### Automatic Deployment

The website is automatically deployed when:
- Changes are pushed to the `main` branch
- Changes are pushed to the `copilot/deploy-latest-version` branch
- The workflow is manually triggered from the Actions tab

### Accessing the Website

Once deployed, the website will be available at:
`https://torbenkapp.github.io/dos-amigos-website/`

### Manual Deployment

To manually trigger a deployment:
1. Go to the repository on GitHub
2. Click on "Actions" tab
3. Select "Deploy to GitHub Pages" workflow
4. Click "Run workflow"

## 📋 Setup Requirements

For the deployment to work, ensure that:
1. GitHub Pages is enabled in repository settings
2. GitHub Pages source is set to "GitHub Actions"

## 🛠️ Development

This is a static website built with:
- HTML5
- CSS3
- Vanilla JavaScript (minimal)

Simply edit the `index.html` and `style.css` files to make changes. Push to the appropriate branch to trigger automatic deployment.
